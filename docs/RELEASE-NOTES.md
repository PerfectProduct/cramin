# Cramin — публичный релиз 0.1.N

Точный номер версии и коммит указаны в манифесте релизного комплекта.

ChatGPT plan доступен в обычных настройках наряду с OpenRouter. Вход выполняется через
Continue with ChatGPT в системном браузере; сессия обновляется автоматически. Каталог аккаунта
позволяет выбрать одну доступную модель для BRIEF, TRANSLATE, EXTRACT, CONSOLIDATE и TOPIC.
Текстовая обработка через ChatGPT не требует OpenRouter-ключа. Новые материалы сохраняют
провайдера, модель и эффективные параметры; начатые материалы сохраняют свой выбор.
Строгие проверки завершения потока, модели, схемы, перевода, исходных якорей и кэша сохранены.
Запросы ChatGPT расходуют лимиты плана или доступные кредиты; стоимость в USD неизвестна
и не рассчитывается по тарифам OpenRouter. Автоматического переключения провайдера нет.
Распознавание аудио (STT) остаётся через OpenRouter и требует прежнего отдельного доступа;
при его отсутствии приложение объясняет причину до запуска распознавания. Скрытого платного fallback нет.

В этой версии импорт статей с MIME text/markdown и text/plain сохраняет строки и абзацы,
учитывает charset и BOM; HTML по-прежнему проходит извлечение статьи. В «Сведениях» READY-документа
доступен read-only экспорт диагностического ZIP через системный выбор файла. Архив содержит текст
и сохранённые ответы модели выбранного документа; храните его как личные данные.

TRANSLATE проверяет соответствие ответа исходным предложениям по индексам, диапазонам,
sourceIds, SHA-256 и неизменяемым якорям, включая сохранённый кэш; запрос ограничен 32 предложениями.
Для новых processing snapshots EXTRACT использует пакеты по 350 слов вместо 700. Удалённая
конфигурация main имеет приоритет над встроенной и применяется также к старым установленным
версиям при создании новых snapshots. Существующие snapshots, jobs и готовые документы сохраняются.

Существующие карточки автоматически не исправляются. Контроль TRANSLATE не доказывает полную
семантическую корректность перевода. Реальное изменение скорости, стоимости и качества при
EXTRACT350 ещё не измерено; уменьшение пакета само по себе не гарантирует ускорение или экономию.

Cramin превращает учебный материал в карточки и помогает изучать его в контексте.
Источники: вставленный текст, PDF с текстовым слоем, статья по ссылке и YouTube.
Поддерживаются английский, русский и иврит в обе стороны; интерфейс на русском.

В документе доступны оригинал, перевод и карточки. Каждая карточка соответствует отдельному
контекстному значению. Категории «Основные», «Связанные», «Общие» определяет модель;
их можно включать независимо в любых сочетаниях, вместе с фильтрами статуса и избранного.
Карточки сохраняются локально. В занятии работают переворот, «знаю»/«ещё учу», точная отмена
последнего действия, продолжение и автопоказ с play/pause. Озвучка зависит от Android TTS и голосов.
Прогресс и промежуточные результаты обработки сохраняются для продолжения после прерывания.

Обновления: после сетевой ошибки «Повторить» повторяет проверку или загрузку.
Отмена установки завершает попытку; новая установка требует явного действия.
Выдача разрешения unknown sources сохраняет возможность продолжить подготовленное обновление.

Для создания карточек нужен готовый выбранный провайдер: ключ OpenRouter со средствами
или подключённый ChatGPT plan с доступной моделью и лимитом. Запросы идут внешним моделям
и расходуют средства/лимиты пользователя. Изучение готовых карточек доступно без обработки;
локальный TTS-голос нужен для гарантированной офлайн-озвучки.

Ограничения: PDF-сканы без текстового слоя не распознаются; сайты с авторизацией, paywall или
защитой могут быть недоступны. YouTube может отказать из-за региона, IP, возраста, авторизации
или изменений сервиса. Авторские субтитры предпочтительны; при их отсутствии транскрипция аудио
стоит денег. Возможны ошибки распознавания, перевода, выделения значений и категорий — проверяйте
карточки по оригиналу. Расходы в сведениях приблизительны и не ограничивают бюджет.

Android 8.0/API26 и выше. Release и debug — разные приложения: установки release поверх debug
с переносом документов/прогресса нет. Сохраните debug для старых занятий. Обновления совместимых
release имеют тот же пакет и постоянную подпись; используйте официальный APK и SHA-256.
