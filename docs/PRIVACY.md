# Данные и внешние сервисы Cramin

Cramin хранит на устройстве документы, оригинал и перевод, предложения, карточки по значениям,
категории, избранное, статусы, незавершённые занятия, промежуточные результаты обработки,
выбранные модели и счётчики расхода. Room и файлы находятся в приватном каталоге приложения.
PDF копируется туда при импорте. Скачанное YouTube-аудио и части транскрипции используются
обработчиком; не считайте приватный каталог временным или автоматически очищенным сразу после
ошибки. Удаление документа удаляет связанные записи и его каталог; удаление приложения удаляет
локальные данные. Общего экспорта/импорта и переноса между debug/release нет.

Ключ OpenRouter сохраняется в DataStore зашифрованным AES/GCM с ключом Android Keystore.
Он отправляется в Authorization только OpenRouter при проверке ключа и обработке. APK не содержит
ключей пользователя. Документ и его части/контекст передаются OpenRouter для перевода,
выделения значений, консолидации и классификации; при транскрипции передаётся аудио.
OpenRouter маршрутизирует запросы выбранным поставщикам моделей: их условия хранения и
обработки также применимы. Cramin не обещает отсутствие хранения данных внешними поставщиками.
[Условия OpenRouter](https://openrouter.ai/privacy) проверяйте перед загрузкой чувствительных материалов.
Обработка платная по тарифам выбранных моделей; оценка расхода в приложении не является лимитом.
Повторная обработка и retry могут создавать дополнительные платные запросы.

При выборе ChatGPT plan текстовые запросы идут напрямую в OpenAI Responses API, а каталог —
в OpenAI Models API. Одна выбранная модель обслуживает все текстовые стадии. Запросы используют
stream=true и store=false; это не обещание полного отсутствия хранения у внешнего сервиса.
Применяются условия выбранного аккаунта OpenAI. Вход проходит в системном браузере через OAuth;
Cramin не получает пароль. Access/refresh tokens зашифрованы AES/GCM с Android Keystore в
noBackupFilesDir и не включаются в snapshots, диагностические отчёты, cloud backup или device transfer.
Ротация сессии выполняется автоматически; отключение очищает локальные токены и запрашивает отзыв
на сервере, сообщая, если удалённый отзыв не подтверждён. Debug и release хранят сессии отдельно.
ChatGPT plan расходует лимиты плана/доступные кредиты; стоимость USD неизвестна. STT остаётся
на OpenRouter. Автоматического перехода к другому провайдеру и скрытого платного fallback нет.

При импорте статьи приложение обращается к указанному сайту (включая сетевые перенаправления).
YouTube extraction обращается к YouTube и его хостам субтитров/медиа, без аккаунта Google.
Эти серверы видят IP и запрашиваемые URL. Автосубтитры YouTube не используются: берутся
авторские субтитры, при отсутствии — аудио для транскрипции через OpenRouter.

Каталог моделей запрашивается у выбранного провайдера. Конфиг моделей OpenRouter загружается с
raw.githubusercontent.com/PerfectProduct/cramin/main/config/models.json при начале обработки
и по кнопке обновления; он может менять эффективные модели и стоимость без нового APK.
Встроенная копия служит fallback; пользовательские overrides имеют приоритет. Этот remote config
не подменяет модель или параметры ChatGPT plan; существующие snapshots сохраняют свой провайдер.
Проверка обновлений по кнопке обращается к GitHub API, скачивание APK и SHA-256 — к GitHub
и хостам его ассетов. Документы и API-ключ этим запросам не прикладываются.

Озвучка использует системный Android TextToSpeech. Текст отправляется установленному TTS-движку;
некоторые движки/голоса используют сеть. Для работы офлайн установите подходящие локальные голоса
и проверьте настройки движка. Отдельного TTS API Cramin не вызывает.

Собственной аналитики и crash-reporting нет. В release util.Log отключён, HTTP logger отсутствует.
Пользователь может сам скопировать диагностику/состояние документа; перед передачей проверьте
содержимое. Это ручное действие, автоматической отправки автору приложения нет.

Android backup включён: документы, база и настройки могут попадать в системную облачную копию
и перенос устройства согласно настройкам Android/OEM. Файл secrets.preferences_pb исключён
из cloud backup и device transfer; после восстановления API-ключ нужно ввести заново.
Это не механизм переноса между разными applicationId и не гарантия восстановления данных.
Сеть приложения запрещает cleartext HTTP на Android; отдельного allowlist хостов в OkHttp нет.
Разрешения: интернет/состояние сети, foreground dataSync, уведомления и установка APK обновлений.
Доступ к PDF даёт выбранный пользователем URI; разрешение на всю память и микрофон не нужны.
