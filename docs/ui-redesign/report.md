## Фактические причины роста lint 31 → 41

Сопоставлены XML lint 0.1.34 и ссылки в исходниках точного HEAD 95ac33f (отдельный detached checkout). Десять новых UnusedResources: create_title_2, doc_header_stats, cards_total, cards_new, cards_starred, cards_filter_starred, cards_all_learned, settings_about, topic_selected, topic_document_totals. Все десять использовались до реорганизации, после неё перестали. Они удалены; также удалены остальные действительно неиспользуемые строки и новые остатки нынешнего редизайна. Параметр Modifier в EmojiBadge переставлен на первое необязательное место. Общие suppression не добавлялись.

## Система компонентов

Layout.kt: NavigationRow (подпись, текущее значение, переход, разделитель), SingleChoice (radio semantics, адаптивный перенос), PrimaryAction / ActionDock (один акцент, безопасная отдельная нижняя область), StatusText. TopicFilters/ChoiceRow: независимые checkbox-строки с границей и явным состоянием; размер зоны не менее 48dp. Поля: отступ страницы 20dp, секции 24dp, внутри группы 8dp. Существующие типографические уровни используются последовательно, основной текст не уменьшен ради вместимости. Палитра синяя; общие формы 8/12/16/20dp, вместо универсальных огромных залитых плиток — строки и разделители. Особая форма учебной карточки/56dp нижние иконки сохранены.

HTML отрендерен установленным Chromium без сети. Отсутствующая внешняя библиотека lucide заменена в рендере условным шевроном; это ограничение касается только иконок макета. Код/обработчики HTML в приложение не переносились.
