## Проверки

Целевой FinishingPassTest проверяет первый запуск и раскрытие дополнительных параметров; ввод/сохранение/проверку синтетического ключа через локальный HTTP-interceptor (внешняя сеть запрещена); отдельное сохранение направления и языка; пустой legacy-набор с сохранённой маской, явное открытие полного набора; частичную классификацию и пересечение с избранным; отмену платного подтверждения; панель слова, статус, избранное, длинный русский текст и Hebrew. Проверки выполняются при реальном системном шрифте, чтобы масштаб распространялся и на окна диалогов.

Ограничения: снимки и тесты на Android-эмуляторе, физический телефон и ручной TalkBack не используются. Голос в наушниках/фон/блокировка не перепроверяются: эти механизмы не затронуты. Визуальная приёмка владельцем не объявляется; первым комплект смотрит архитектор.

Первый целевой прогон: 2 теста × 3 системных масштаба (100/150/200%) прошли; дополнительно панель при 320dp/100% и существующий TopicFiltersUiTest.normalFont — успешно. Просмотр PNG выявил оставшуюся клавиатуру после ввода ключа: завершение onboarding теперь явно снимает фокус и скрывает IME. Для съёмки основных экранов используется путь «пропустить без ключа», а сохранение/проверка ключа проверяются отдельно в конце; инструментальный ввод больше не перекрывает следующие кадры системной клавиатурой. Повтор целевого теста навигации нужен для окончательной съёмки обоих путей первого запуска; полный набор не запускался.
