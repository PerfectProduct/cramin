## 5. Что не проверено и почему

- Установка и смоук на **реальном телефоне** — зона владельца (промпт).
- **`release.yml`, `ci.yml`, `instrumented.yml` в GitHub Actions** — ветка не запушена (push/PR только владелец);
  workflow'ы написаны по образцу TheyGrow и проверены локально эквивалентными командами (`assembleRelease` с подписью,
  `verify_release_signature.py`, `sha256sum`).
- **Загрузка удалённого `config/models.json`** — до слияния в `main` URL отдаёт 404; код обрабатывает это как «конфига нет»
  и использует встроенную копию (проверено на эмуляторе).
- **Сценарий обновления внутри приложения** (Releases → скачивание → PackageInstaller) — релизов на GitHub ещё нет;
  проверены компоненты (разбор релиза, SHA-256, отмена) юнит-тестами, а обновление поверх — установкой release 0.1.9
  поверх 0.1.8 через adb с сохранением документа, статусов и незавершённой сессии.
- **PDF через UI** (ACTION_OPEN_DOCUMENT и share application/pdf) — извлечение проверено на фикстуре (Robolectric),
  UI-путь вручную не прогонялся.
- **Голос TTS для иврита** на эмуляторе отсутствует — 🔊 скрывается, в настройках подсказка; логика проверена на en/ru.

## 6. Долги и риски

- **NewPipeExtractor** хрупок: YouTube меняет формат, возможны требования po_token/капчи с некоторых IP; при отказе —
  «YouTube изменил формат. Проверьте обновления» и обновление зависимости релизом.
- **STT**: провайдерский таймаут 60 с на запрос и 25 МБ multipart — куски по 10 минут укладываются, но очень длинные
  видео стоят долго; `whisper` иногда путает языки без явного `language`.
- **Стоимость длинных документов**: извлечение `gemini-3.8-flash` — главная статья (~$0.2–0.3 на 4000 слов; с
  `gemini-3.1-flash-lite` в 5 раз дешевле, но нестабильно пропускает термины глоссария).
- **«Избегание глоссария»** извлекающими моделями: термины из брифа (до 80) реже становятся отдельными карточками
  (например, «library» в ручном прогоне). Промпты зафиксированы SPEC; страховочный проход по глоссарию — в бэклоге.
- Release без R8 (APK ≈ 20 МБ); стоп-лист ru содержит 383 формы (ориентир 150–300 превышен из-за падежных форм).
- В общей колоде при продолжении сохранённой сессии смыслы дубликатов из других документов не объединяются заново.

## 7. Действия владельца до первого релиза

1. Просмотреть `docs/screenshots/` и `docs/model-bakeoff/`, дать «ок» на push (ветка `feat/v1`, 11 коммитов).
2. `git push -u origin feat/v1`, открыть PR в `main` с этим отчётом (`gh pr create --base main --body-file docs/pr-v1.md`),
   дождаться зелёного `ci.yml` (и при желании запустить `instrumented.yml`), влить.
3. Проверить, что `https://raw.githubusercontent.com/PerfectProduct/cramin/main/config/models.json` отдаёт файл.
4. Убедиться, что `gh secret list --repo PerfectProduct/cramin` показывает три секрета подписи и
   `release-signing/cert-sha256.txt` — отпечаток вашего keystore; сделать бэкап `~/.cramin/release.p12`.
5. Запустить **release** workflow на `main` → релиз `v0.1.N` с двумя ассетами.
6. Поставить APK на телефон, пройти ручной смоук SPEC §14.3 (чеклист ниже), затем — обновление N → N+1 через
   «Проверить обновления».
7. Следить за расходом ключа OpenRouter (лимит кредита на ключе разработки — рекомендуется).

## Чеклист ручного смоука (SPEC §14.3)

- [ ] Реальный ключ введён в онбординге, «Проверить ключ» показывает остаток.
- [ ] Статья по ссылке → «Карточки готовы: N слов», вкладка «Текст» с подчёркиваниями.
- [ ] YouTube с авторскими субтитрами → текст, абзацы по паузам.
- [ ] YouTube без авторских субтитров (1–3 мин) → «Транскрипция…» → карточки.
- [ ] PDF через «📁 Файл PDF» и через «Поделиться»; скан даёт «PDF не содержит текстового слоя».
- [ ] Скопированный текст; текст на языке перевода блокируется.
- [ ] Иврит в обе стороны (he→ru, en→he): RTL по содержимому, огласованная лемма, 🔊 при наличии голоса.
- [ ] Сессия: переворот, свайпы, счётчики, ↶ возвращает статус и счётчик, ▶ автопроигрывание, сводка раунда,
      «Повторить L невыученных».
- [ ] Выход посреди сессии → «Продолжить с K/N».
- [ ] Общая колода «Все невыученные», чипы пар языков, свайп меняет статус у дубликатов.
- [ ] Обновление N → N+1 через «Проверить обновления» с сохранением статусов карточек.
