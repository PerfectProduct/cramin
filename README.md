# Cramin

Cramin — Android-приложение для изучения слов из своих материалов. Вставьте текст, выберите
PDF с текстовым слоем или укажите ссылку на статью/YouTube: приложение подготовит перевод
и двусторонние карточки. Языки: английский, русский, иврит в любых парах; интерфейс русский.

## Установка и начало работы

Скачивайте `cramin-v0.1.N.apk` и
его `.sha256` из [официальных Releases](https://github.com/PerfectProduct/cramin/releases).
Проверьте `sha256sum -c cramin-v0.1.N.apk.sha256`, разрешите установку для своего браузера или
файлового менеджера и установите APK. Требуется Android 8.0/API26 или выше.
Следующие совместимые release устанавливаются поверх и сохраняют данные. В настройках есть
проверка обновлений; установку подтверждает Android. Debug имеет отдельный пакет и публичного
канала обновлений нет. Release не переносит документы и прогресс debug: оставьте debug установленным
для старых материалов, а новые создавайте в release. Общего экспорта/импорта пока нет.

В обычных настройках выберите OpenRouter или ChatGPT plan. Для OpenRouter введите собственный
ключ и проверьте его; обработка оплачивается по тарифам выбранных моделей. Для ChatGPT нажмите
Continue with ChatGPT, войдите через системный браузер и выберите одну модель из каталога аккаунта
для всех текстовых стадий. Запросы расходуют лимиты плана или доступные кредиты; стоимость USD
неизвестна. Автоматического переключения провайдера и скрытого платного fallback нет.
Распознавание аудио остаётся через OpenRouter и требует отдельного доступа.
Оценка расходов в Cramin не гарантирует предел расходов. Подготовка требует сети; готовые документы и занятия
сохраняются локально. [Данные и конфиденциальность](docs/PRIVACY.md) описывают внешние запросы,
Android backup и TTS.

## Материалы и обучение

Создайте материал из текста, PDF, статьи или YouTube; можно также использовать «Поделиться».
В документе переключайтесь между чтением оригинала/перевода и карточками. Одно контекстное
значение даёт одну карточку; повторные упоминания остаются примерами и контекстом.
«Основные», «Связанные», «Общие» назначает модель. Включайте категории в любых сочетаниях,
добавляйте фильтр статуса и избранного. У старого/неполного результата категории можно дополнить.

В занятии тап переворачивает карточку, свайп вправо — «знаю», влево — «ещё учу»; Undo отменяет
последнее действие. Прерванное занятие можно продолжить. Play/pause включает автопоказ;
озвучка использует Android TTS. Для офлайн-озвучки установите локальные голоса нужных языков.
Сведения документа показывают модели, расход и диагностику; retry может снова стоить денег.

PDF-сканы без текстового слоя, закрытые статьи и некоторые YouTube-видео недоступны.
YouTube использует авторские субтитры; иначе приложение транскрибирует аудио через OpenRouter.
Региональные/IP/возрастные ограничения и изменения YouTube могут помешать импорту.
Перевод, распознавание и категории могут ошибаться: проверяйте важные карточки по оригиналу.

## Сборка и лицензии

Kotlin/Compose, Room, WorkManager, minSdk26, target/compile36. JDK21, Android SDK36,
build-tools36.0.0; полная история git нужна для версии `0.1.<git rev-list --count HEAD>`.

```bash
./gradlew assembleDebug testDebugUnitTest lintDebug -Plive=false
scripts/test-device.sh # только эмулятор, fake API, без оплачиваемых тестов
scripts/build-release.sh # существующий keystore вне репозитория
```
